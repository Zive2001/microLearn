## 🚨 **Troubleshooting AI Issues**

### **Issue 1: AI Service Unavailable**
**Error:** `"AI service temporarily unavailable"`  
**Solution:** 
1. Check OpenAI API health endpoint
2. Verify API key in environment variables
3. Check OpenAI service status

### **Issue 2: Poor Question Quality**
**Error:** Irrelevant or poorly formed questions  
**Solution:**
1. Check topic spelling in request
2. Verify user level is correctly set
3. Review OpenAI prompt engineering in service

### **Issue 3: Slow AI Response**
**Error:** Questions take >10 seconds to generate  
**Solution:**
1. Check internet connectivity
2. Monitor OpenAI API rate limits
3. Consider reducing max_tokens in OpenAI config
