# Avatar Models Directory

This directory should contain GLB 3D avatar models for the TalkingHead system.

## Required Files:
- `ava-avatar.glb` - Female avatar (Ava)
- `andrew-avatar.glb` - Male avatar (Andrew)

## Compatible Model Sources:

### ReadyPlayerMe (Recommended)
1. Visit https://readyplayer.me/
2. Create free avatars
3. Download as GLB format
4. Rename files to match expected names

### Mixamo (Alternative)
1. Visit https://www.mixamo.com/
2. Download character models
3. Export as GLB format
4. Ensure models have proper facial morph targets

## Model Requirements:
- Format: GLB (GLTF Binary)
- Facial morph targets for lip-sync
- Rigged for animations
- Optimized for web (under 10MB recommended)

## Technical Notes:
The TalkingHead library expects models with:
- Standard bone naming conventions
- Facial blend shapes/morph targets
- Clean topology for real-time rendering
- Materials compatible with Three.js PBR
